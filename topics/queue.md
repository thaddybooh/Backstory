**How it works**

- Issues alternate between World and Singapore. The next issue takes the **first topic in "Up next"
  that matches its track**.
- If there is no matching topic, Claude picks the biggest story of the day for that track.
- Write one topic per line, starting with `- world:` or `- singapore:`. Anything after ` -- ` is a note
  for Claude (an angle, a question to answer, a source to use).
- When an issue is written, its topic moves from "Up next" to "Published" in the same pull request.
