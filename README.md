# But Why?

*There is always more to the story.* A daily long-form explainer: one story in the news each day, alternating
between World and Singapore, with the background you need to understand it.

- **GUIDE.md**: plain-language steps for publishing, previewing and adding issues.
- **NOTES.md**: design and technical decisions, current status and next steps.
- **BRIEF.md**: the original brief.

Built with [Astro](https://astro.build). Issues live in `src/content/issues/` as MDX files.

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # fetch Commons photos, then build to dist/
```
